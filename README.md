# FR-IDGE — Biodiversity of the French overseas territories

Analyses of the documented biodiversity of the 15 French overseas territories,
carried out for the overseas component of **FR-IDGE**, a research-action project
(INRAE – OFB, 2026–2029) developing the reporting of the genetic diversity
indicators of the Kunming-Montreal Global Biodiversity Framework:

- **Ne > 500** (A.4) — proportion of populations within species with an
  effective population size above 500;
- **Maintained populations** (A.CY.22) — proportion of populations maintained
  within species.

These analyses describe what the national taxonomic reference says about each
territory, as a basis for selecting the species that the indicators will be
computed on.

## Contents

| Script | Purpose |
|---|---|
| `scripts/prepare_taxref_om_all_biodiv.R` | Builds the long-format extraction (taxon × territory × status) from TAXREF v18 |
| `scripts/all_biodiv_OM.R` | Descriptive analyses: taxonomic and habitat profiles, species–area relationship, endemism, introduction pressure, erosion, taxa shared between territories |
| `scripts/fridge_theme.R` | FR-IDGE plotting charter (colours, theme, export helper) |

Work in progress: `species_targets_OM.R`, the allocation of target species
between territories and taxonomic groups (Hébert et al. 2026 rule).

## Repository layout

```
.
├── data/
│   ├── territories_metadata.csv      # territory attributes (region, area, labels)
│   └── clean_allbiodiv/              # TAXREF extraction, regenerated, not versioned
```

Outputs (`*_results/` folders: figures and tables) are regenerated by the
scripts and are not versioned.

## Reproducing the analyses

1. Download TAXREF v18 from the INPN (<https://inpn.mnhn.fr/telechargement/referentielEspece/taxref>).
2. Run `scripts/prepare_taxref_om_all_biodiv.R` to build
   `data/clean_allbiodiv/allbiodiv_om_v18_long.csv`.
3. Set `WORKING_DIR` at the top of each script to the root of this repository,
   then run `scripts/all_biodiv_OM.R`.

Requires R with `data.table` and `ggplot2`.

## Conventions

- Counting unit: taxon by `CD_REF`; species and subspecies together unless
  stated otherwise.
- Native taxa: TAXREF statuses `P`, `E`, `S`. Introduced (`I`, `J`),
  cryptogenic (`C`) and casual (`B`) taxa are excluded wherever shared or
  endemic biota are compared.
- Code and comments in English, figure labels in French.

## Data source

Gargominy O., Tercerie S., Régnier C., Ramage T., Dupont P., Daszkiewicz P. &
Poncet L. 2025. *TAXREF, référentiel taxonomique pour la France : méthodologie,
mise en œuvre et diffusion.* Rapport PatriNat (OFB-CNRS-MNHN), Muséum national
d'Histoire naturelle, Paris. 47 pp.

TAXREF v18 is the version used here; the release of v19 has been delayed since
the July 2025 cyberattack on the Muséum.
